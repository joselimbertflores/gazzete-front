# Gaceta - Frontend

Aplicación web del sistema de **Gaceta**, diseñada para mostrar publicaciones y permitir la consulta de documentos PDF.

## Descripción

El frontend permite a los usuarios acceder a las publicaciones disponibles, visualizar documentos en formato PDF y consultar información asociada a cada publicación.

## Funcionalidades principales

- Visualización de publicaciones
- Consulta de documentos PDF
- Descarga de archivos
- Búsqueda de publicaciones
- Listado de documentos publicados
- Interfaz de administración para gestionar publicaciones

## Requisitos previos

Antes de iniciar, asegúrate de tener instalado:

- Node.js
- npm
- Angular CLI
